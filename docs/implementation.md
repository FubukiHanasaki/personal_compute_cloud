## 安全设计审查

节点凭证与用户密钥独立；任务只运行登记且可验证隔离的模板；本地/云端策略取交集。生产只接受 PostgreSQL 与安全 cookie。Agent 仅出站 HTTPS，默认本地维护模式，配置能力不足则拒绝。数据库租约过期进入 reconciling，只有确认旧进程已退出才能重试。首个受控计算模板只处理有界数字输入；测试模型必须显式启用并标明 synthetic，不代表真实 GPU 验收。
